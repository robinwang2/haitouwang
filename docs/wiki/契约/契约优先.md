`contracts/` 是接口的**唯一事实源**：

- `contracts/openapi/openapi.json` —— HTTP 接口
- `contracts/schemas/domain.schema.json` —— 领域机器字段完整约束
- `contracts/events/event.schema.json` —— 事件

**实现与契约冲突以契约为准。** 要改契约走技术策划单，不在实现单里偷改。

校验：`redocly lint contracts/openapi/openapi.json` + `tooling/scripts/validate-contracts.mjs`
（在 `tooling/` 下 `npm run contract`）。

选型背景见 [[技术栈基线]]。
