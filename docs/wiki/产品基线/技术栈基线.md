| 层 | 选型 |
|---|---|
| Web 客户端 | TypeScript + React（Next.js） |
| 云端 API / 任务执行器 | TypeScript + Node.js（NestJS），契约优先；执行器与 API 同代码库不同进程 |
| 主数据库与向量检索 | PostgreSQL 唯一主存储 + pgvector，**不引入独立向量数据库** |
| 队列/缓存 | Redis + BullMQ |
| 对象存储 | S3 兼容协议，经存储抽象层接入 |
| 本地辅助代理 | TypeScript + Playwright，无 GUI 后台服务 + 托盘/CLI，**不做 Electron 壳** |
| AI 集成 | Provider Adapter 抽象层，**不在业务代码硬编码单一供应商 SDK** |

契约优先的具体口径见 [[契约优先]]。
