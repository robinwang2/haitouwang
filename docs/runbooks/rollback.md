# MVP 回滚手册

## 回滚触发

出现未确认提交、重复提交、跨租户访问、审计失败、迁移校验差异、错误率持续超阈值、队列无法排空或可信证据状态错误时立即停止发布并回滚。具体数值阈值须在生产可观测性工单中批准；安全不变量被破坏时不等待数值阈值。

## 回滚顺序

1. 暂停创建新的生成、评审和申请命令；保留只读查询与人工任务访问。
2. 撤销受影响代理令牌，停止 worker 领取新任务；记录运行中命令及其幂等键，不清空队列。
3. 将 Web/API/worker 回退到发布前不可变镜像摘要。代理协议不兼容时保持代理暂停，禁止自动降级协议。
4. 默认保留向前兼容数据库结构；只有经过演练的逆迁移才可执行。任何数据删除都必须另行审批。
5. 恢复后运行契约、鉴权/跨租户、人工降级、无证据不成功和幂等回执烟测。
6. 逐项恢复只读、生成/评审、填写能力；提交能力最后恢复，并要求新的用户确认。

## 数据与证据保护

- 不删除或重写申请时间线、审计、outbox、回执消费记录和第三方证据。
- 对结果不确定的命令标记待核验，不自动重试。
- 保存发布前备份、失败版本和回滚版本的摘要与时间；不保存敏感正文。

## 当前候选限制

当前没有生产镜像、生产 IaC、业务数据库迁移或持久化备份，因此只能回滚代码候选，不能执行生产数据回滚。`-Mode Production` 门禁必须保持失败，直到部署与恢复演练的外部证据完成。
