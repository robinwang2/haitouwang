## 1. 使用方式与安全门禁

本文使用“必须”“不得”描述可执行控制。相关功能上线前，开发者必须按每类对象的“控制措施”提供测试或审计证据；未满足的控制视为发布阻断项。本文只固化已经确认的安全约束。第 4 节中的供应商、跨境、地域、司法管辖和具体保留天数仍由责任人决策，本文不代替制作人作出产品决策。

### 1.1 数据分类

| 级别 | 定义 | 示例 | 最低处理要求 |
|---|---|---|---|
| 极敏感 | 泄露后可直接接管第三方账户或绕过验证的数据 | 原始登录凭证、Cookie、验证码、OAuth refresh token | 原始登录凭证、Cookie、验证码仅限本地；不得进入云端、AI 输入或普通日志。授权令牌须加密、最小权限、可撤权 |
| 敏感个人数据 | 可识别用户、求职经历或通信关系的数据 | 简历、附件、事实库、邮件正文、申请记录 | 租户隔离、传输/静态加密、最小权限、日志脱敏、可导出、可删除 |
| 受限业务数据 | 会影响求职决策但通常不直接接管账户的数据 | 职位描述、匹配结果、AI 草稿、幂等键 | 按用户隔离、完整性校验、访问审计 |
| 低敏感元数据 | 不含正文和秘密的运行数据 | 任务状态、错误类别、时间戳 | 数据最小化；禁止通过拼接还原敏感内容 |

### 1.2 全局不变量

1. **凭证隔离**：原始登录凭证、Cookie、验证码不得离开用户设备，不得进入云端 API、队列、对象存储、数据库、崩溃报告、遥测、AI 输入或普通日志。日志只允许记录不可逆用户/任务标识、动作、结果和错误类别。
2. **本地/云端隔离**：目标招聘网站的浏览器配置、Cookie 与本地密钥存储不得保存云端凭证；云端短期令牌不得写入目标网站的浏览器上下文。二者使用独立存储、独立进程权限和独立生命周期。
3. **短期令牌与重放保护**：本地代理只接受限定用户、设备、用途和受众的短期令牌；令牌必须有 `exp`、唯一 `jti`/nonce，并通过 TLS 传输。接收方须校验签名、受众、到期时间和 nonce；一次性命令消费后记录 `jti`，重复请求返回原结果或拒绝执行，不得重复提交。
4. **撤权传播**：用户撤权、退出设备或账户删除后，云端立即拒绝新任务并使相关授权不可再用；本地代理在下次命令前校验授权。邮件撤权后停止拉取、队列任务不得续跑。各层只记录撤权事件和不含秘密的标识。
5. **数据主体能力**：文件、事实库和邮件同步数据必须支持按用户导出与删除。删除需覆盖主存储、对象存储、索引、缓存和待执行队列；备份清除期限受 4.4 待决项约束，决定前不得宣称即时物理清除。
6. **误投防护**：默认在提交前停止并要求用户人工确认；未确认不得提交。每次申请使用稳定幂等键并由服务端唯一性约束防止重复提交。验证码、在线测评、视频面试、电子签名、未知法律/身份/歧义工作授权问题，以及无法确认提交结果的页面，必须暂停并降级人工，不得静默重试或猜答。
7. **最小权限与脱敏**：API、任务执行器、对象存储、数据库、AI 适配器和邮件连接器均按用户、对象、动作授予最小权限；生产日志使用字段白名单，禁止记录请求/响应正文、Authorization、Cookie、验证码、邮件正文、简历正文和模型完整提示词。

## 2. 六类对象逐项模型

### 2.1 登录

| 字段 | 记录 |
|---|---|
| 数据分类 | 原始用户名/密码、Cookie、验证码为**极敏感**；不含秘密的登录状态、设备标识为低敏感元数据。 |
| 数据流 | 用户在本地受控浏览器中输入目标网站凭证 → 目标网站；Cookie 写入本地专用浏览器配置。云端仅接收“已登录/需人工/已退出”等状态，不接收凭证、Cookie、验证码或页面表单秘密。 |
| 信任边界（云端/本地/第三方） | 本地设备负责秘密输入和保存；云端只编排不含秘密的任务；目标招聘网站是第三方。秘密跨本地→第三方边界时直接由浏览器经 TLS 发送，不经过云端。 |
| 威胁场景 | 日志或崩溃报告泄密；恶意任务诱导上传 Cookie；验证码被自动绕过；云端命令遭重放；多用户任务串线。 |
| 控制措施 | 凭证字段禁止序列化到云端 DTO；日志字段白名单与秘密模式扫描；验证码出现即暂停转人工；任务绑定用户/设备；短期令牌校验 `exp`、受众、`jti`/nonce；消费记录和幂等响应防重放；租户鉴权测试。上线证据：凭证泄漏负向测试、重放测试、跨租户拒绝测试。 |

### 2.3 事实库

|---|---|
| 数据分类 | 经历、教育、技能、身份和工作授权事实为**敏感个人数据**；来源引用、版本和置信状态为受限业务数据。 |

### 2.4 AI

| 字段 | 记录 |
|---|---|
| 数据分类 | 模型输入中获准的文件片段、事实和邮件片段为**敏感个人数据**；职位描述、提示模板、模型草稿和评审结果为受限业务数据。原始登录凭证、Cookie、验证码属于禁止输入。 |
| 数据流 | 云端任务按用户授权选取最少数据 → 凭证/秘密过滤与提示组装 → Provider Adapter → 第三方 AI → 输出验证 → 草稿/评审结果；草稿必须经用户审核，不能直接触发提交。4.2 未决前，生产环境不得启用外部 AI 数据调用。 |
| 信任边界（云端/本地/第三方） | 云端数据选择器、Provider Adapter 与第三方 AI 是独立边界；供应商、处理地域和跨境路径未确定。AI 输出是不可信输入，进入业务系统前必须校验。 |
| 威胁场景 | 过量披露；凭证随提示泄露；供应商训练/保留数据；跨境传输；提示注入和数据外带；模型编造事实；输出导致误投。 |
| 控制措施 | Provider Adapter 统一执行字段允许清单、数据最小化和秘密检测，命中原始凭证/Cookie/验证码时阻断；普通日志不记提示词或完整响应；租户隔离；输出按结构校验并标明引用，不能生成未经确认的新事实；提交前人工确认；供应商启用须先完成 4.2、4.3 的书面决策和相应配置/合同核验。上线证据：秘密 canary 阻断、提示注入、跨租户、日志扫描、虚构事实及“无人工确认不提交”测试。 |

### 2.5 浏览器会话

| 字段 | 记录 |
|---|---|
| 数据分类 | 本地浏览器配置、目标站点 Cookie/session storage 为**极敏感**；页面内容和待填表单为敏感个人数据；命令状态为低敏感元数据。 |
| 数据流 | 云端下发绑定用户/设备且不含目标站点秘密的短期命令 → 本地代理校验 → 专用浏览器配置访问第三方网站 → 本地填写 → 提交前暂停等待人工确认 → 云端仅回传脱敏状态/申请标识。Cookie、验证码和表单秘密不回传。 |
| 信任边界（云端/本地/第三方） | 云端编排、本地代理、专用目标站点浏览器上下文、第三方招聘网站四个边界。目标站点浏览器配置与云端令牌存储必须在目录、进程权限和生命周期上严格隔离。 |
| 威胁场景 | 云端令牌被注入页面或浏览器扩展读取；Cookie 被上传；命令重放造成重复提交；页面结构变化误投；恶意页面操纵本地代理；撤权后离线任务继续。 |
| 控制措施 | 云端短期令牌放在浏览器上下文之外的本地受限存储；目标站点 Cookie 只在专用本地配置中；命令校验签名、用户、设备、受众、`exp`、`jti`/nonce；幂等键与唯一约束阻止重复提交；默认提交前人工确认；未知字段、验证码或无法确认结果时暂停转人工；撤权检查失败即停止队列并清除可撤销云端令牌。上线证据：存储隔离检查、过期/撤权/重放命令测试、重复提交测试和页面未知状态人工分流测试。 |
| 剩余风险 | 被攻陷的本地设备、恶意浏览器扩展或第三方页面可读取本地会话；本地残留及云端事件的具体清理周期仍受 4.4 影响。 |

### 2.6 邮件授权

| 字段 | 记录 |
|---|---|
| 数据分类 | 邮箱密码不得收集；OAuth refresh/access token 为**极敏感**；邮件正文、附件、地址和线程关系为敏感个人数据；同步游标为受限业务数据。 |
| 数据流 | 用户在邮件供应商授权页完成 OAuth → 供应商向受控回调返回授权码 → 云端交换并在秘密存储中加密保存令牌 → 连接器以最小 scope 拉取必要邮件/状态 → 用户导出、删除或撤权。撤权后立即停止新同步并取消待执行同步任务。 |
| 信任边界（云端/本地/第三方） | 用户浏览器、云端 OAuth 回调/秘密存储/连接器和第三方邮件供应商是独立边界；邮箱密码、Cookie、验证码不得经过云端系统。 |
| 威胁场景 | scope 过宽；授权码/令牌进入日志；回调 CSRF；令牌重放；撤权后后台继续同步；邮件提示注入；删除后正文或附件残留。 |
| 控制措施 | 使用 OAuth 授权码流程及 PKCE/state；只申请实现同步所需的最小 scope；短期 access token、refresh token 加密存储和受限服务身份；令牌/授权码/邮件正文日志脱敏；回调一次性 state 与授权码防重放；撤权事件使授权状态失效、停止拉取并取消队列；同步数据可导出、可删除，删除传播到正文、附件、索引、缓存和队列；邮件内容进入 AI 前按 2.4 过滤且仅取必要片段。上线证据：scope 快照、CSRF/重放、日志扫描、撤权后零拉取、导出与删除传播测试。 |
| 剩余风险 | 邮件供应商自身保留和司法管辖、令牌撤销传播延迟、同步数据地域及删除/备份周期尚未完全确定，见 4.3、4.4；若邮件内容进入 AI，另受 4.2 约束。 |

## 3. 控制验证矩阵

| 控制 | 必须通过的验证 | 失败处理 |
|---|---|---|
| 凭证不出本地 | 用测试凭证/Cookie/验证码覆盖 API、队列、对象存储、普通日志和 AI 适配器；云端不得出现原值 | 阻断发布，删除测试残留并修复数据路径 |
| 日志脱敏 | 扫描应用、任务、代理、崩溃和审计日志；Authorization/Cookie/验证码及文件、事实、邮件正文命中数为 0 | 阻断发布并轮换可能泄露的令牌 |
| 最小权限与租户隔离 | 六类对象均有跨租户拒绝测试；存储/连接器权限与声明 scope 快照评审 | 阻断发布并收窄角色/scope |
| 删除与导出 | 文件、事实库、邮件同步数据的导出可解析且完整；删除后主存储、对象存储、索引、缓存、队列均不可读取 | 阻断发布；备份清理由 4.4 决策后补充时限验证 |
| 撤权传播 | 撤销本地代理或邮件授权后，新任务被拒绝，排队任务取消，邮件不再同步 | 阻断发布并调查仍有效的授权副本 |
| 误投防护 | 未人工确认不能提交；相同幂等键不产生第二次提交；未知问题、验证码和结果不确定均进入人工队列 | 阻断发布，不允许以自动重试规避 |
| 短期令牌与重放 | 过期、错误受众、错误设备、已消费 `jti`/nonce 全部拒绝；撤权令牌不能执行 | 阻断发布并轮换签名/会话材料 |
